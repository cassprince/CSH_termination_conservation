Methods
    Software and their version numbers can be found in linux_commands.txt. Software citations can be found in citations.txt. 

Termination protein acquisition and analyses
    Genomes and protein annotations were downloaded from the NCBI bacterial reference genomes database, which contains >22,000 genomes. In this database, approximately one reference genome is assigned to every bacterial species. Only reference genomes with >80% CheckM completeness and <10% CheckM contamination were included in our search, and our resulting database included 18,944 genomes. Amino acid sequences for proteins involved in translation termination (RF1, RF2, RF3, PrmC, PrfH, SelB, PylS) were detected using HMMER3 (hmmsearch) with an E-value cutoff of 0.05. HMMER profiles were built with amino acid sequences as annotated by NCBI Prokaryotic Genome Annotation Pipeline. Sequences from multiple species in diverse phyla were included in the HMMER profiles, except for PylS because it is phylogenetically restricted. The score results of the hmmsearch were plotted on a histogram to identify score cutoffs for each protein. The hits were subsequently filtered by score as follows: RF1 >340; RF2 >350; RF3 >500; PrmC >200; PrfH >115; SelB >220; PylS >150. Assembly names and accession numbers, protein presence data, and taxonomies for each genome can be found in Table_S1.csv.

Phylogenetic analyses
    Maximum-likelihood trees were built with the GToTree pipeline and Universal single copy gene set published by Hug et al. The simplified tree in Fig 2A was created with one random genome from each phylum. Genomes were randomly selected using the “sample_n” function from dplyr v1.2. The accession numbers for the random genomes can be found in Table_S2.csv. Taxonomic classifications were assigned according to the NCBI Taxonomy database and downloaded using NCBI Datasets.
