Methods
    Software and their version numbers can be found in linux_commands.txt. Software citations can be found in citations.txt. 

Termination protein search and analyses
    Genomes and protein annotations were downloaded from the NCBI bacterial reference genomes database, which contains >22,000 genomes. In this database, approximately one reference genome is assigned to every bacterial species. Only reference genomes with >80% CheckM completeness and <10% CheckM contamination were included in our search, and our resulting database included 18,944 genomes. Amino acid sequences for proteins involved in translation termination (RF1, RF2, RF3, PrmC, PrfH) were detected using HMMER3 (hmmsearch) with an E-value cutoff of 0.05. HMMER profiles were built with amino acid sequences as annotated by NCBI Prokaryotic Genome Annotation Pipeline. Sequences from multiple species in diverse phyla were included in the HMMER profiles. The score results of the hmmsearch were plotted on a histogram to identify score cutoffs for each protein. The hits were subsequently filtered by score as follows: RF1 >340; RF2 >350; RF3 >500; PrmC >200; PrfH >115. Assembly names and accession numbers, protein presence data, and taxonomies for each genome can be found in Table_S1.csv.

Phylogenetic analyses
    Maximum-likelihood trees were built with the GToTree pipeline and Universal single copy gene set published by Hug et al. The simplified tree in Fig 3A was created with one random genome from each phylum. Genomes were randomly selected using the “sample_n” function from dplyr v1.2. The accession numbers for the random genomes can be found in Table_S2.csv. Taxonomic classifications were assigned according to the NCBI Taxonomy database and downloaded using NCBI Datasets.

Bacterial RF protein homolog analysis
	HMMER was used as previously to identify bacterial RF homologs in protein annotations of the following NCBI reference genomes from multiple bacteria, archaea, and eukaryotes: GCF_000009045.1 (Bacillus subtilis), GCF_000005845.2 (Escherichia coli), GCF_022984195.1 (Synechococcus elongatus), GCF_000011905.1 (Dehalococcoides mccartyi), GCF_000022005.1 (Caulobacter vibroides), GCF_000182925.2 (Neurospora crassa), GCF_000146045.2 (Saccharomyces cerevisiae), GCF_034140825.1 (Oryza sativa Japonica Group), GCF_000001735.4 (Arabidopsis thaliana), GCF_000715075.1 (Nicotiana tabacum), GCF_000001405.40 (Homo sapiens), GCF_016699485.2 (Gallus gallus), GCF_000002985.6 (Caenorhabditis elegans), GCF_000001635.2 (Mus musculus), GCF_035594765.1 (Anolis carolinensis), GCF_000001215.4 (Drosophila melanogaster), GCF_052040795.2 (Danio rerio), GCF_000007345.1 (Methanosarcina acetivorans), GCF_008000775.2 (Promethearchaeum syntrophicum), GCF_000022445.1 (Saccharolobus islandicus). Bacterial RF1, RF2, and ArfB proteins and mitochondrial ICT1 were used as queries. Resulting protein hits were aligned using MAFFT and the tree was built using FastTree. The tree was visualized with ggtree and midpoint rooted using phangorn. Proteins were categorized as "mitochondrial" or "chloroplastic" if these terms were used in the NCBI protein annotation.
